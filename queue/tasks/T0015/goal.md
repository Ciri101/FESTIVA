# 队列用法补充“快速收尾”两步流程

## 范围

- 要交付：tool/queue-usage.md 新增“快速收尾”一节：两步流程（读一次状态并备好交接正文；一条命令连写并提交）；每笔写入前现场取新状态版本并核对序号只因自己的写入前进，否则停下读变化；同一任务连写时 `--expect` 的推算方法；可复制的命令片段；中途停下与重试、暂存范围、与他人未提交改动的处理；说明它不豁免任何现有规则。
- 不包含：修改队列工具代码；修改 AGENTS.md 或其他文件；复刻 envshell 的交接备忘或开场钩子。
- 允许修改的位置：tool/queue-usage.md。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 新增一节且与现有规则一致 | 阅读新增一节，对照 queue/AGENTS.md 与 tool/queue-usage.md 其余各节 | 仍要求读过变化、携带 context 与 revision、稳定请求号、同批暂存、不绕过钩子；没有新增豁免 |
| A2 | 命令片段可用 | 在会话草稿目录的仓库克隆中，按片段实跑一次“领取 → 释放 → 提交”连写；再用错误的预期序号模拟中途有他人写入 | 连写成功、提交检查通过；模拟他人写入时片段在写入前停下，机器账不变 |
| A3 | 没有改动其他内容 | `git diff` | 只有 tool/queue-usage.md 新增的一节 |
| A4 | 链接可用 | 本地相对链接检查 | 无断链 |

验收安排：Agent 自检后交付；用户验收。
