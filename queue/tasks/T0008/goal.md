# UI 设计文档修订

## 范围

- 要交付：修订 truth/ui/FESTIVA-高保真设计文档.md：
  1. 页面清单与导航关系；逐页界面说明，区分“画面事实 / 已定界面要求 / 待确认”，规则只引用产品设计文档。
  2. 修正评审发现的事实错误（日期与星期、匹配百分比、配色描述、角色对应等）。
  3. 视觉语言：按 E3 统一使用 iOS 系统字体；色彩、控件与系统适配要求。
  4. 未出图页面（A3）的界面要点，功能定义引用产品设计文档。
  5. 附录：E1 样例数据表（用户、活动、申请）；E2 改图清单（供学生修图）；裁决→章节对照表。
  6. 按 F1 为每节标状态。
- 不包含：产品规则的定义（归产品设计文档）；修改 reference/ 中的图片；工程实现。
- 允许修改的位置：truth/ui/FESTIVA-高保真设计文档.md。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 本文件负责的裁决全部落实 | 按裁决→章节对照表逐题核对 | 每题有对应章节，内容与裁决一致 |
| A2 | 画面描述与参考图一致 | 按 gate/checks.md“FESTIVA 文档与参考图核对”逐图核对 | 没有与图片矛盾的事实陈述；样例数据不被写成真实数据 |
