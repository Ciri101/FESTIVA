# 检查清单

## 默认队列检查

- Agent 接手时：`python3 tool/task_queue.py doctor`。
- 提交时：由安装的 Git 钩子调用 `check --staged`，无需用户手工维护。
- 队列工具开发时：`python3 -B -m unittest discover -s gate -p 'test_*.py' -v`。测试真实 CLI、进程锁、Git 提交和中断恢复，写入临时项目；不在每次业务提交时全跑。

队列检查只证明机械规则与记录一致，不证明项目产物正确或批准来源已经独立认证。

## 隔离 Agent 使用验收

当入口说明、队列用法或恢复流程发生重要变化时，按 [隔离验收规约](subagent-e2e.md) 另做空白上下文的真实 Agent 使用测试。它不替代程序测试，也不自动随业务提交运行；结果需区分模板缺陷、执行环境阻断和未覆盖范围。

## 项目专属检查

### FESTIVA 文档与参考图核对

- 对象：`truth/` 中基于 `reference/` 图片编写的设计和工程文档。
- 工作目录与前置条件：项目根目录；图片与文档存在，无需额外软件。
- 方法：逐个打开文档引用的图片，核对页面/组件名称、主要文字和关系；检查相对链接可打开；确认“画面可见事实”“建议”“待确认”没有混写。
- 通过条件：引用的图片存在，文档描述有对应画面证据，未把静态截图里的样例认证、日期、人数、费用或匹配分数写成真实运行事实。
- 限制：人工核对不能验证点击行为、真实数据、后端实现或用户是否批准；这些要用原型、测试和用户验收另行证明。
- 来源：2026-09-28，FESTIVA 当前 C4 图与 10 张高保真图片的文档整理需求。

执行输出与失败记录归对应任务，本清单不保存“上次通过”的状态。
